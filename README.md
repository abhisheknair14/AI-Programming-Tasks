# AI Programming Tasks

This repository contains three AI and web development projects developed as part of programming tasks.

## Projects

### 1. Login and Registration System
A user authentication application built using React and Firebase.

**Technologies:** React, JavaScript, Firebase

### 2. AI PDF Question Answering Chatbot (RAG)
An AI-powered chatbot that extracts information from PDF documents and retrieves relevant content to answer user questions.

**Technologies:** Python, Groq API, Sentence Transformers, NumPy, PyPDF

### 3. AI Website Summarizer
An AI-powered application that extracts website content and generates easy-to-understand summaries.

**Technologies:** Python, Groq API, BeautifulSoup, Requests
